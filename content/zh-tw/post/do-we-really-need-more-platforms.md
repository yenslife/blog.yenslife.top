# 我們還需要更多的平台嗎？

(以下故事皆為真人手打，沒有 LLM 潤飾與改寫，但有些是真的有些是假的，大家笑笑就好)
## 一個 AI 加值的教學平台

我的大學專題就是做一個平台，一個 AI 加持的教學平台。聽起來太籠統了，我收斂一下，你可以想成 Coursera + LLM 助教的組合平台，為每一個課程微調一個助教 LLM。但說真的我們真的需要平台嗎？我們之所以做這個平台，背後想要解決的問題就是遠距教學的痛點，遠距教學沒有人可以問 ，這也是我當時修 Cousera 課程有遇到的問題，所以其實可以算是我個人的痛點。我修了一堂 Objective-C App 教學課程，但說真的，都 2023 了 (我大二的時候)，誰還在用 Objective-C 做 Native IOS App 啊！大家都馬用 Swift。不僅課程的 Xcode 版本是我修課當下最新 Xcode 版本的 1/2 倍 (沒錯就是差這麼多)，不論是 UI 甚至是很多功能都不一樣了。

講太多我自己的痛點了，我那時候還寄信給系主任，後來還變成 Cousera 助教，這個下次再聊吧哈，這是個很有趣的體驗。回到平台本身，所以這個平台的目標是讓學生在遠距上課的時候有一個人可以問，對吧？2026 的 LLM 已經強大到可能甚至不需要一個特化的 LLM 來處理不同課程的問題，但我個人覺得這個想法在當時還是挺新穎的。

為什麼我會有這樣的疑問呢？因為不論是創業競賽，還是專題，只要想做的東西是軟體，好像都逃離不了平台的命運。平台這個東西就好像是各種想法的終點，是規模化或者說要變成產品的最後一哩路。如果我要解決的問題是「在看影片的同時學習外語」，那我可能只會想要做成一個 Youtube 的 Chrome 插件。但如果我要把學習外語這件事做大，讓大家都把時間留在我的 Server 裡，那我似乎一定要把這個插件擴展成一個平台。從一個單純的「Youtube 字幕加強版」，變成我可以記錄你的學習時數，現在有學習時數了，那我應該要提供你更多資源，根據你學習的語言，你愛看的影片來進行推薦，所以我要設計一個演算法，而這個演算法必須要跑在我的 server 上，因為他是閉源的，花拉，我開始花時間設計我的平台，設計前端後端資料庫，設計導流的連結讓大家可以訂閱這個服務，甚至找不太紅的 Youtuber (因為他們我才請得起) 來做聯盟行銷。

但回到我的初心，我只是想要把韓文學好，才能聽懂 Chodan 在講什麼，我才不要用什麼平台。

現在的 Coding Agent (泛指一切可以呼叫工具並進行程式碼撰寫的基於 LLM 的軟體) 這麼強，我應該可以自己寫一個吧？所以我應該連搜尋現有產品這段都跳過，直接基於我個人的需求開發一個 Chrome 插件來學習外語，但我想要分享出去，於是我將這個產品開源了。開始有人在 GitHub 上發 Issue 給我一些其他功能的建議，而我也用 Codex 將它實作出來。也有使用者用 Email 告訴我，可以加 xxx 功能，而我也覺得不錯，所以我一樣用 Codex 將它實作出來。然後這個瀏覽器插件就越來越肥，肥到當瀏覽器啟用這個擴充套件的時候會有點卡，網頁上也越來越多按鈕。到後來我的腦子不知道哪根筋不對，我覺得這麼多功能，應該要寫一個完整的網頁來呈現才對。於是我開始設計前端後端資料庫，設計導流的連結讓大家可以訂閱這個服務，甚至找更不紅的 Youtuber 來...

## Sindre Sorhus 給我的啟發

大神中的大神，對他的介紹大家可以看差評君的介紹影片

https://youtu.be/SGKvQHF3rOY?si=G3OfAHo2YVuFJMOc

{{< youtube SGKvQHF3rOY >}}

他設計的軟體都小小的，但都能夠確實解決一個問題，雖然我們手機裡面的 App 已經夠多了，我們用的平台也夠多了。但 Sindre 設計的 App 小到我覺得值得下載，因為他簡潔、優雅又不佔空間，Simple but not Easy。

於是我開始在想，這些創業比賽、黑客松的終點是什麼？是另一個要找到登出按鈕難如登天的 App，還是介面複雜到我懶得學習的平台？我都不想要誒，與其說是終點不如說是墳墓。我又不想要當 Google 或 Meta 的 CEO，我不想要 host 太多東西，我只是想要優雅地解決一個痛點而已。還是說不做成平台就賺不到錢？又或者只有像我這樣的人才會想這麼多，誰管你是不是優雅解決，只要複雜到用戶看不懂，反正用戶都是笨蛋，掏錢我才讓他變簡單就好。

幹，這樣超窩囊的好嗎？而且在某個層面來說挺不道德的。

那我可以怎麼做呢？什麼都不做？不，我們應該要讓付費買斷軟體這件事變成主流，讓訂閱制徹底死亡，歌頌可以完全持有一個東西的制度，並讚揚職人精神，從你我做起。
